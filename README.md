# フラクタルガチャ

After Effects のフラクタルノイズを、ランダム生成で何度でも引き直せる ScriptUI パネルです。
「いい感じのノイズ」を出すためにパラメータを手で詰める作業を、ボタン一つに置き換えます。

![デモ](docs/demo.gif)

## できること

- ボタン一つでフラクタルノイズのパラメータをランダム生成
- 生成範囲を指定して、狙った方向性の中でランダム化
- ランダム化するプロパティを個別に選択

## 動作環境

| 項目 | 内容 |
| --- | --- |
| After Effects | CC 2025 / 2026 |
| OS | Windows 11（macOS は未検証） |

## インストール

1. `フラクタルガチャ.jsx` をダウンロードします。
2. 下記のフォルダに配置します。
   - Windows: `C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Scripts\ScriptUI Panels`
3. After Effects を再起動します。
4. `ウィンドウ` メニューの一覧に `フラクタルガチャ.jsx` が追加されます。

## 使い方

<img src="docs/panel.png" width="360">

1. 対象のレイヤーを選択します。
   - フラクタルノイズが未適用のレイヤー → 新規に適用されます
   - すでに適用済みのレイヤー → 既存のエフェクトの値が変更されます
2. ランダムに変化させたいプロパティにチェックを入れます。
3. 各プロパティの下限・上限を設定します（左が下限、右が上限。未設定の場合は既定値）。
4. 「ガチャ」ボタンを押します。
5. 結果が気に入らなければ、そのまま押し直します。

## 実装のポイント

### 対象プロパティの絞り込み

フラクタルノイズには多くのパラメータがありますが、自分のプロジェクトファイルや
配布されているプロジェクトファイルを確認し、調整頻度の高い4項目に絞りました。
すべて並べるとパネルが縦に伸びて目的の項目を探す手間が増えるため、
網羅性より操作の速さを優先しています。

### 1項目分をまとめて関数化

ラベル・入力欄2つ・チェックボックスを1セットとして `createRangeInput` に関数化し、
上下限の範囲チェックも `limitInputValue` に集約しました。
項目を追加するときに直す箇所が分散しないため、
レイアウトの崩れやバリデーションの漏れが起きません。
なお、左右に並ぶ入力欄はどちらが下限か判別しづらいため、
ラベルを増やす代わりに helpTip で補っています。

### Undo グループを try/finally で保護

`beginUndoGroup()` と `endUndoGroup()` を `try...finally` で挟み、
途中で例外が出ても Undo スタックが開いたままにならないようにしています。
ここが崩れると After Effects 側の取り消し履歴ごと壊れるためです。

```javascript
app.beginUndoGroup("フラクタルガチャ");
try {
    // エフェクトの取得・追加、値の適用
} finally {
    app.endUndoGroup();
}
```
### 入力値の検証を一箇所に集約

各パラメータの上下限チェックを `limitInputValue` にまとめ、
プロパティへ値を渡す前に必ず通しています。
バリデーションを呼び出し側に散らすと、パラメータを追加するたびに
チェック漏れが起きるため、追加時に一箇所だけ見れば済む形にしました。

### 対象プロパティの絞り込み

フラクタルノイズには多くのパラメータがありますが、自分のプロジェクトファイルや配布されている
プロジェクトファイルを確認し、実際に調整頻度の高い4項目に絞りました。
すべてを並べるとパネルが縦に伸び、目的の項目を探す手間が増えるため、
機能の網羅性よりも操作の速さを優先しています。

### ScriptUI パネルの構造

ラベル・入力欄2つ・チェックボックスを1セットとして `createRangeInput` に関数化し、
パラメータごとに呼び出す構成にしました。
1項目あたりの余白やサイズ指定が1箇所にまとまるため、
項目を追加してもレイアウトの一貫性が崩れません。

### 入力欄の役割を helpTip で補足

下限・上限の入力欄が左右に並ぶ形のため、どちらがどちらか判別しづらい問題がありました。
ラベルを追加するとパネルが煩雑になるので、ツールチップで補う方法を選んでいます。
